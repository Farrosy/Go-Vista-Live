CARA PASANG DI UNITY
1. Font emoji
   - Salin ke Assets/Fonts/NotoColorEmoji.ttf
   - Klik kanan file font > Create > TextMeshPro > Font Asset > Color.
   - Pilih font asset yang baru: Atlas Population Mode = Dynamic, atlas 1024x1024 (cukup untuk chat).
   - Edit > Project Settings > TextMesh Pro > Settings: tambahkan font asset tadi ke "Emoji Fallback Text Assets".
   - Teks chat dan kolom input WAJIB pakai TextMeshPro (TMP_Text / TMP_InputField).
     Komponen Text lama (legacy) tidak bisa menampilkan emoji berwarna.
   - Ukuran build bertambah sekitar 10 MB karena file font ikut masuk.
2. Ikon
   - Salin folder Icons ke Assets/Sprites/Chat
   - Pilih semua PNG > Texture Type = Sprite (2D and UI), centang Alpha Is Transparency, Apply.
   - Kalau pakai versi @2x, atur ukuran Image tetap 128 (gelembung) atau 64 (kirim); gambarnya jadi lebih tajam.
   - Tombol kirim: Image = btn-send, Button > Transition = Sprite Swap, Pressed Sprite = btn-send-pressed.
